🎢 Painel de Gestão - Beto Carrero World

Sistema web interativo desenvolvido para o gerenciamento de visitantes, controle de clientes e monitoramento de fluxo por setores do Beto Carrero World. O projeto reúne visualização de dados em tempo real, tabelas dinâmicas e informações das atrações do parque.

🚀 Funcionalidades Atuais

Dashboard Analítico: Visualização dinâmica da distribuição de visitantes por setores utilizando gráficos interativos desenvolvidos com Chart.js.

Gestão de Setores: Página dedicada (setores.html) para organização e acompanhamento das áreas temáticas do parque.

Tabela de Clientes: Listagem estruturada para controle e visualização dos visitantes/clientes cadastrados no sistema.

Interface Responsiva: Layout atualizado com estilização separada para a estrutura geral das páginas e para os componentes gráficos.

🛠️ Tecnologias Utilizadas

HTML5 — Estruturação das páginas (index.html e setores.html).

CSS3 — Estilização das interfaces e dos gráficos.

JavaScript (ES6+) — Lógica de negócio, manipulação dinâmica do DOM e gerenciamento de dados.

Chart.js — Biblioteca utilizada para renderização e atualização dos gráficos do painel.
